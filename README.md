# Сервис форм отклика

Конструктор форм для стажировок и мероприятий: от публикации ссылки до просмотра откликов и аналитики.

## Возможности

- **Конструктор:** создание черновика, настройка вопросов и обязательных полей.
- **Публикация:** уникальная ссылка для студентов, заполнение без регистрации.
- **Управление приёмом:** закрытие и повторное открытие формы. После публикации вопросы неизменяемы.
- **Отклики:** просмотр всех ответов в панели менеджера.
- **Аналитика:** просмотры, начала, отправки и незавершённые заполнения с последним активным полем.

> Заполнение считается незавершённым после 30 минут бездействия. Аналитика считает попытки, а не уникальных людей; неотправленные ответы не сохраняются.

## Типы полей

| Поле | Назначение |
| --- | --- |
| Короткий текст | Краткий ответ, например имя |
| Длинный текст | Развёрнутый ответ |
| Email | Адрес электронной почты с проверкой формата |
| Один вариант | Выбор одного ответа из списка |
| Несколько вариантов | Выбор нескольких ответов |
| Город проживания | Поиск по справочнику городов с регионами |
| Вуз | Поиск по справочнику российских вузов |
| Направление обучения | Поиск по коду или названию направления |
| Уровень и курс | Бакалавриат 1–4+, магистратура 1–2+, специалитет 1–5+ |

Любое поле можно сделать обязательным. В справочных полях принимаются только значения из списка; уровень курса должен соответствовать выбранному направлению. Знак «+» означает указанный курс и выше.

## Быстрый старт

Нужен **Node.js 20 или новее**. Выполните из корня проекта:

```sh
npm install
npm start
```

**Панель менеджера:** [http://localhost:3000/admin](http://localhost:3000/admin) — без авторизации. Ссылка для студентов появится после публикации формы. Другой порт задаётся переменной окружения `PORT`.

Во время работы интернет и внешние сервисы не требуются. Если при установке недоступен готовый нативный модуль SQLite для вашей платформы, понадобятся Python и инструменты сборки C++.

## Данные

- **Хранилище:** SQLite, файл `data/forms.sqlite`. Данные сохраняются после перезапуска; старые JSON-данные не переносятся.
- **Резервная копия:** остановите сервер и скопируйте каталог `data/`.
- **Справочники:** локальные снимки. Источники, ограничения охвата и обновление — в [документации справочников](catalogs/README.md).
