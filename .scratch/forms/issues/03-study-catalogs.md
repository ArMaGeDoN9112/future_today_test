# 03: Направления, уровни и курсы обучения

**What to build:** приложение автономно предоставляет через HTTP справочник российских направлений и допустимые сочетания уровня и курса. Студент впоследствии сможет выбрать курс самостоятельно либо в соответствии с уровнем направления; UI ещё не создаётся.

**Blocked by:** 01 — Запуск, хранение и жизненный цикл форм.

**Status:** done

- [x] Найден и проверен пригодный источник направлений; подготовлен локальный набор с происхождением, датой, условиями использования, правилами отбора и известными ограничениями. Исследовательская ссылка сама по себе не считается готовым набором.
- [x] Включены бакалавриат, специалитет и магистратура; СПО, аспирантура и отдельные профили вузов не включаются. Небольшой демонстрационный список не выдаётся за требуемый справочник.
- [x] Запись направления содержит устойчивый идентификатор, код, название и уровень образования. Поиск через HTTP возвращает эти сведения и позволяет различать уровни одинаково названных направлений.
- [x] Предусмотрено получение допустимого значения по идентификатору; неизвестные значения не принимаются за существующие записи.
- [x] Подготовлен фиксированный набор вариантов «Уровень и курс обучения»: бакалавриат — 1, 2, 3, 4+; магистратура — 1, 2+; специалитет — 1, 2, 3, 4, 5+.
- [x] Знак «+» означает указанный курс и выше. Точный курс внутри последней группы не требуется; варианты подписаны понятно и имеют устойчивую идентичность.
- [x] Через HTTP можно получить все варианты курса либо только варианты уровня выбранного направления. Получение курса не требует обязательного выбора вуза или направления.
- [x] Вуз и направление остаются независимыми: справочник не вводит проверку того, преподаётся ли направление в конкретном вузе.
- [x] Справочники включены в поставку и не скачиваются при запуске. Описан порядок обновления разработчиком без редактора в административной панели.
- [x] HTTP-тесты проверяют поиск направлений, код и уровень результатов, точные согласованные варианты курсов, фильтрацию по уровню и отказ для неизвестного значения. UI в этом тикете не создаётся.
