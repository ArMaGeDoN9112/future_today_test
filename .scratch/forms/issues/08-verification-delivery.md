# 08: Полная проверка и подготовка сдачи

**What to build:** проверяющий получает воспроизводимо запускаемый сервис с подтверждённым полным сценарием, инструкцией, сохранённым исходным логом AI и публичной ссылкой на GitHub. Итоговая проверка объединяет ранее проверенные серверные и браузерные сценарии.

**Blocked by:** 06 — Интерфейс менеджера; 07 — Интерфейс студента.

**Status:** in-progress

- [x] Пройден полный браузерный сценарий: менеджер создаёт черновик со справочными полями, публикует ссылку, студент отправляет отклик, менеджер видит ответы и соответствующие показатели аналитики.
- [x] Проверены закрытие и повторное открытие по прежней ссылке, неизменяемость содержания, сохранение предыдущих откликов и продолжение приёма.
- [x] Существующие HTTP- и браузерные тесты проходят вместе; проверки из предыдущих тикетов не откладываются впервые до этого этапа.
- [x] Проверены чистая установка на Node.js 20 или новее, запуск строго командами `npm install` и `npm start`, адрес по умолчанию `http://localhost:3000`, административная панель `/admin` и изменение порта через `PORT`.
- [x] После перезапуска доступны прежние формы, их состояния, отклики и сведения для аналитики; основные сценарии работают без внешних API, ключей, облачных сервисов и отдельно устанавливаемой СУБД.
- [x] Проверены публичная форма на узком экране, доступность выбора справочных значений с клавиатуры и безопасное отображение пользовательских подписей и ответов.
- [x] Выполнен итоговый code review по двум осям: соблюдение правил проекта и соответствие согласованной спецификации. Выявленные ошибки исправлены и затронутые проверки повторены.
- [x] Подготовлена инструкция запуска и проверки, ограничения аналитики, источники и ограничения справочников, порядок их обновления разработчиком и сохранения данных. Непроверенная полнота данных не заявляется.
- [ ] Сохранён доступный полный исходный лог работы с AI для собеседования. Заметки с пересказом решений не выдаются за полный лог; если экспорт недоступен агенту, это явно фиксируется как необходимое действие до окончательной сдачи.
- [ ] Подготовлен публичный GitHub-репозиторий с решением и инструкцией; проверяющему доступна ссылка. Локальные файлы или отсутствие настроенного remote не выдаются за завершённую публикацию.
- [x] Коммиты используют Conventional Commits: английский префикс типа и описание на русском языке.
- [ ] Итог сдачи содержит проверенную ссылку на публичный репозиторий. Ограничения или невыполненные обязательные условия не скрываются.
