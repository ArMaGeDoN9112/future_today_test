# 04: Отправка, проверка и просмотр откликов

**What to build:** через HTTP можно получить опубликованную форму, отправить корректный отклик и прочитать его как менеджер. Все проверки выполняются сервером; принятые отклики сохраняются и не теряются при одновременных отправках. UI ещё не создаётся.

**Blocked by:** 02 — Справочники городов и вузов; 03 — Направления, уровни и курсы обучения.

**Status:** done

- [x] Через HTTP доступны отправка отклика и просмотр списка откликов конкретной формы с количеством и ответами по её полям.
- [x] Принимаются все согласованные типы ответов: короткий и длинный текст, email, один вариант выбора, город, вуз, направление, уровень и курс.
- [x] Сервер проверяет обязательность и типы ответов, формат email и принадлежность выбранного варианта вопросу. Некорректная отправка возвращает понятную ошибку и не создаёт отклик.
- [x] Справочные ответы проверяются по локальным данным. Произвольные строки, несуществующие идентификаторы и подмена вида справочника отклоняются прямым HTTP-запросом.
- [x] Необязательные справочные поля можно пропустить. Обязательное поле нельзя заменить свободным текстом или отправить без допустимого значения.
- [x] Если выбраны направление и курс, их уровни должны совпадать. Несовместимая пара, в том числе оставшаяся после смены направления, отклоняется сервером.
- [x] Курс без направления допустим, если форма не требует заполнения направления; вуз и направление не проверяются на взаимное соответствие.
- [x] Черновик и закрытая форма не принимают отклики. После повторного открытия доступны новые отправки, а прежние отклики остаются доступными.
- [x] Каждая намеренная успешная отправка создаёт отдельный отклик; повторное заполнение не заменяет предыдущую запись и не требует регистрации студента.
- [x] Успешный ответ возвращается после сохранения. Отклики разных форм не смешиваются, параллельные корректные отправки не теряют данные, ошибки сохранения не маскируются.
- [x] Принятые отклики и соответствие ответов исходным вопросам сохраняются после перезапуска и не искажаются при обновлении справочников.
- [x] HTTP-тесты покрывают полный сценарий от публикации до чтения отклика, отрицательные проверки, сохранность после перезапуска и конкурентные отправки через внешние операции приложения.
- [x] Контракты отправки и чтения доступны последующим задачам. UI в этом тикете не создаётся.
