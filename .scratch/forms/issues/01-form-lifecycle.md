# 01: Запуск, хранение и жизненный цикл форм

**What to build:** менеджер через HTTP создаёт и изменяет черновик, публикует форму по уникальной ссылке, закрывает и повторно открывает приём. После перезапуска формы и их состояния сохраняются. Это первый работающий серверный сценарий; интерфейс ещё не создаётся.

**Blocked by:** None (can start immediately).

**Status:** done

- [x] Приложение работает на Node.js 20 или новее и запускается из корня командами `npm install`, затем `npm start` без дополнительных ручных шагов.
- [x] Порт по умолчанию — 3000, переменная окружения `PORT` меняет порт. Работающее приложение не требует внешних сервисов, API-ключей и отдельно устанавливаемой СУБД.
- [x] Через HTTP доступны список форм, создание и чтение черновика, изменение названия и набора полей, публикация, закрытие и повторное открытие приёма.
- [x] Черновик поддерживает метаданные всех согласованных типов полей: короткий текст, длинный текст, email, выбор одного варианта, город, вуз, направление, уровень и курс обучения. У поля есть устойчивая идентичность, подпись и обязательность; у выбора одного варианта — заданные менеджером варианты.
- [x] Менеджер может добавлять, изменять и удалять поля черновика. Некорректная структура формы отклоняется сервером понятной ошибкой.
- [x] Публикация фиксирует содержание формы и возвращает уникальную публичную ссылку. Операция чтения публичной формы выдаёт её содержание; черновик для публичного заполнения недоступен.
- [x] Сервер отклоняет изменение содержания после публикации, включая закрытую и повторно открытую форму. Возврата в редактируемый черновик нет.
- [x] Закрытие и повторное открытие меняют только доступность приёма; ссылка и содержание остаются прежними. Публичная операция позволяет отличить закрытую форму и показать завершение приёма.
- [x] Формы и состояния сохраняются внутри проекта. Перезапуск не теряет данные; ошибки сохранения не выдаются за успех, конкурентные изменения не повреждают хранилище.
- [x] HTTP-тесты проверяют жизненный цикл, отказ в изменении опубликованной формы, недоступность черновика и сохранность после перезапуска через внешние операции приложения, без чтения внутреннего формата хранилища.
- [x] Выбранные HTTP-контракты и порядок запуска описаны настолько, чтобы следующие задачи использовали существующие операции. UI в этом тикете не создаётся.
