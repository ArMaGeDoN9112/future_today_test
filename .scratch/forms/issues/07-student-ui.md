# 07: Интерфейс студента

**What to build:** студент по публичной ссылке без регистрации заполняет форму с телефона или компьютера, выбирает допустимые справочные значения и отправляет отклик. Интерфейс показывает результат и сообщает события аналитики без содержимого неотправленных ответов.

**Blocked by:** 05 — Попытки заполнения и аналитика. Эта зависимость также закрепляет согласованный порядок: весь серверный этап завершается до начала UI. Тикет не зависит от интерфейса менеджера.

**Status:** done

- [x] По опубликованной ссылке отображаются название, поля, подписи и обязательность на русском языке; регистрация студента не требуется.
- [x] Поддерживаются короткий и длинный текст, email, выбор одного варианта и все согласованные справочные поля. Форма пригодна для телефона и доступна с клавиатуры.
- [x] Город, вуз и направление выбираются через поиск по серверным справочникам. Показываются регион города и код, название, уровень направления; произвольная строка без выбора не считается справочным ответом.
- [x] Если совпадений нет, показывается сообщение «Нет нужного варианта? Свяжитесь с организатором». Необязательное поле можно пропустить; обязательное без выбора блокирует отправку.
- [x] Вуз и направление выбираются независимо. Поле уровня и курса работает без направления; при выборе направления доступны только курсы соответствующего уровня.
- [x] Варианты курса соответствуют согласованным группам: бакалавриат 1–4+, магистратура 1–2+, специалитет 1–5+. Несовместимый выбранный курс сбрасывается при смене уровня направления.
- [x] Ошибки обязательных полей, email, справочных значений и серверного отказа понятны пользователю и позволяют исправить ответ. Ложного подтверждения успеха нет.
- [x] На время отправки кнопка заблокирована. После успешного ответа сервера показывается подтверждение; новое намеренное заполнение может создать отдельный отклик.
- [x] Закрытая форма показывает «Приём завершён» и не позволяет отправку. Если приём закрылся во время заполнения, серверный отказ корректно объясняется пользователю.
- [x] Новая вкладка начинает отдельную попытку; обновление страницы продолжает текущую без нового просмотра. Новое заполнение после успеха получает новую попытку.
- [x] Первое изменение отправляет событие начала; последующая активность обновляет время и последнее активное поле. Фокус без изменения до начала не создаёт начатое заполнение.
- [x] Аналитические события содержат идентичность попытки и поля, но не значения ответов. Неотправленные ответы не сохраняются на сервере или в постоянном браузерном хранилище; сохранение технической идентичности попытки не сохраняет введённый текст.
- [x] Браузерные проверки покрывают поиск и выбор с клавиатуры, соответствие курса направлению, ошибки, отправку, подтверждение, повторное заполнение, продолжение попытки после обновления и закрытую форму. Проверяются узкий экран и безопасное отображение пользовательского текста.
