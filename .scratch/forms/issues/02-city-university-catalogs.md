# 02: Справочники городов и вузов

**What to build:** приложение автономно предоставляет через HTTP поиск и чтение допустимых значений российских городов проживания и вузов. Данные подготовлены из проверенных источников и пригодны для последующей проверки откликов; UI ещё не создаётся.

**Blocked by:** 01 — Запуск, хранение и жизненный цикл форм.

**Status:** done

- [x] Проверены доступность, формат и условия повторного использования исходных данных городов и вузов. Результаты ранее проведённого исследования используются как кандидаты, а не как доказательство наличия готовых наборов.
- [x] Подготовленные локальные справочники включены в поставку. Обычный запуск через npm не скачивает их и не требует сети.
- [x] Для каждого набора указаны источник, дата получения, охват, известные ограничения и правила отбора. Небольшой демонстрационный список не подменяет требуемый российский справочник; неподтверждённая полнота не заявляется.
- [x] Записи имеют устойчивые идентификаторы и названия. У города сохранён регион, позволяющий различать одноимённые города.
- [x] Через HTTP можно найти варианты по названию и получить запись по идентификатору. Неизвестный идентификатор не считается допустимым значением.
- [x] Поиск возвращает достаточно сведений для будущего интерфейса: название города и регион либо название вуза. Отсутствие совпадений корректно отличается от ошибки сервера.
- [x] Справочники доступны проверке откликов из той же версии локальных данных, которую использует поиск; результаты поиска не являются единственной проверкой допустимости.
- [x] Описан воспроизводимый порядок обновления разработчиком с сохранением достоверности ранее полученных откликов. Редактор справочников для менеджера и обновление при запуске не добавляются.
- [x] HTTP-тесты проверяют поиск, различение одноимённых городов, чтение существующей записи, отсутствие неизвестного значения и работу без внешнего подключения.
