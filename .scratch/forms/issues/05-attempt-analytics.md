# 05: Попытки заполнения и аналитика

**What to build:** приложение через HTTP учитывает попытки заполнения и возвращает менеджеру показатели прохождения формы и последние активные поля незавершённых заполнений. Поздняя отправка корректирует показатели; содержимое неотправленных ответов не сохраняется. Этот тикет завершает серверную логику до начала UI.

**Blocked by:** 04 — Отправка, проверка и просмотр откликов.

**Status:** done

- [x] Через HTTP можно начать попытку просмотра формы, продолжить её, сообщить об активности и получить аналитику конкретной формы. Операции и идентичность попытки описаны для последующего браузерного клиента.
- [x] Единица учёта — попытка, а не уникальный человек. Продолжение попытки после обновления страницы не увеличивает просмотры; новая вкладка и новое заполнение после успеха могут создавать отдельные попытки.
- [x] Первое изменение поля отмечает начало заполнения. Открытие страницы и фокус без изменения не считаются началом.
- [x] Учитываются время последней активности и последнее активное поле начатой попытки; содержимое полей в события не включается и на сервере не сохраняется.
- [x] Идентичность формы и поля в событиях проверяется; события одной формы не изменяют аналитику другой. Повторная доставка события начала или завершения одной попытки не завышает соответствующие показатели.
- [x] Начатая попытка без отклика с паузой менее 30 минут находится «В процессе»; при паузе 30 минут и более считается незавершённой. Событие закрытия вкладки для расчёта не требуется.
- [x] Возобновление активности корректирует состояние. Поздняя успешная отправка связывается с нужной попыткой и исключает её из незавершённых; завершённая попытка не становится незавершённой от ожидания.
- [x] Просмотр без изменений остаётся просмотром и не входит в незавершённые заполнения. Неуспешная отправка не отмечается как завершение.
- [x] Аналитика возвращает просмотры, начала, отправленные отклики, заполнения в процессе и незавершённые заполнения, а также последние активные поля незавершённых попыток.
- [x] Последнее активное поле описывается как место остановки, а не доказанная причина ухода. Показатели не называются числом уникальных студентов.
- [x] Сведения для аналитики переживают перезапуск вместе с формами и откликами.
- [x] HTTP-тесты проверяют начало и отсутствие начала, повторные события, изоляцию попыток, границу 30 минут без реального ожидания, возврат, позднюю отправку и сохранность после перезапуска. Проверяется внешнее поведение, а не внутренний формат хранения.
- [x] Серверные контракты готовы для обоих интерфейсов. UI в этом тикете не создаётся.
