# Локальный трекер

- Спецификация: `.scratch/<feature>/spec.md`.
- Каждая задача: `.scratch/<feature>/issues/<NN>-<slug>.md`, нумерация начинается с 01.
- Статус записывается строкой `Status:` в начале задачи.
- Зависимости записываются строкой `Blocked by: NN, NN`.
- Обсуждение дописывается в раздел `## Comments`.

«Опубликовать в трекере» означает создать локальный файл.
«Получить задачу» означает прочитать указанный файл.
