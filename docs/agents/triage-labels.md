# Метки задач

- needs-triage — требуется оценка задачи.
- needs-info — нужны дополнительные сведения.
- ready-for-agent — задача готова к реализации агентом.
- ready-for-human — требуется реализация человеком.
- wontfix — задача не будет выполняться.

В локальном трекере метка указывается в строке `Status:`.
