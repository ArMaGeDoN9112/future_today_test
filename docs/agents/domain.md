# Документация предметной области

Используем один контекст.

Перед изучением проекта:
- прочитай `GLOSSARY.md`, если он существует;
- прочитай относящиеся к задаче решения в `docs/adr/`.

Если документов нет, продолжай работу. Создавай их по мере согласования терминов и архитектурных решений.

Используй термины из глоссария. Если предложение противоречит существующему ADR, явно укажи противоречие.
