# Содержание формы фиксируется при публикации

Менеджер может редактировать форму только до публикации. После публикации содержание формы неизменяемо: это сохраняет соответствие полученных откликов исходным вопросам и исключает необходимость хранить версии вопросов. Закрытие и повторное открытие приёма откликов по прежней ссылке не меняют содержание формы, а полученные отклики сохраняются. Решения согласованы с пользователем 22 октября 2026 года.
